# CA-6.3 媒体ファネル診断ルール監査

## 結論

2026年7月の実データでは、媒体ファネルをPrimary Diagnosisへ組み込まず、当面は参考表示またはActionの補助確認項目に限定することを推奨する。マイガール増加は比較可能な候補を作れる一方、Talkは上位群中央値が0になるキャストがあり、相対比がUNCOMPUTABLEになりやすい。また7月末の媒体値は`isPartial`であり、Primary判定へ接続すると欠測・比較母数の揺れを診断へ持ち込む。

## 母集団・方法

- 期間: 2026-07-01〜2026-07-31
- 依頼記載の母集団: メイン出勤者57名
- 実際に`getCastDiagnosis`が返した母集団: メイン出勤者60名、全キャスト88名
- 監査は実データの60名を正式母集団とし、57名との差を注記した。
- ○は既存Comparisonの`relativeRatio >= 0.8`、×は0.8未満。null／UNCOMPUTABLEは○×へ変換しない。
- マイガールは`heavenMyGirlAdds`（累計スナップショット差分から生成した増加数）、写真は`photoNominationsPer100Uu`、流入はTown UU、結果は平均時給と成約/時間を使用した。
- 既存EngineのDiagnosis／Action／Priorityには接続していない。

## Primary／Action／HIGH影響

仮適用は監査用の表示だけであり、Primary変更は0名、実Action変更は0名、Priority変更は0名、実HIGH変更は0名。仮Action候補と現行Actionが異なる組合せは33件あるが、これは「もし接続した場合に再検討が必要な候補」であり、本番結果ではない。現行の実データActionはHIGH 3名（依頼記載の2名とは差異）だった。

媒体RuleをPrimaryへ入れた場合、Dが20名、Eが12名と広く、OTHER_REVIEWや再来系診断を増やすリスクがある。Talkは中央値0のため、B/C/Fの比率判定は比較群の作り方に依存する。

## Rule採用判断

- Diagnosis: 今回は不採用。欠測・ZERO・UNCOMPUTABLEと比較母数0の影響が大きい。
- Action: 自動Actionの上書きは不採用。スタッフが見る補助確認項目（参考表示）なら将来候補。
- 参考表示: 採用候補。マイガール増加数、100アクセスあたりマイガール増加、Talk送信数をAvailability付きで表示する。

再監査条件は、完全月の確定データ、Talkの非ゼロ比較群、比較可能キャスト数の安定、成約母数不足キャストの除外である。
